# 운동 기록 (Workout Log)

웨이트 트레이닝 기록용 Expo / React Native 앱입니다. 서버 없이 기기에 저장됩니다.

## 기능

- **루틴** — 자주 하는 운동 구성(종목 + 세트 수)을 저장하고 한 번에 시작
  - 루틴 화면에서 부위별 세트 수, 예상 소요 시간(지난 기록 기준), 종목 목록 확인
  - 시작하면 지난번 무게·횟수로 세트가 미리 채워짐
  - 진행한 운동을 그대로 루틴으로 저장 가능
- **근육 부위 그림** — 종목마다 운동 부위를 강조한 인체 그림(앱 자체 제작 SVG)
- **종목 메뉴(⋮)** — 종목별 휴식 시간, 종목 메모, 세트별 메모, 순서 변경, 다른 종목으로 교체, 기록 분석, 슈퍼세트, 삭제
  - 슈퍼세트로 묶은 종목은 그룹의 마지막 종목 세트를 끝냈을 때만 휴식 타이머가 시작됨
- **홈** — 이번 주 요일 표시(운동한 날 점 표시), 연속 운동 주 배지
- **운동 기록** — 종목별 세트 × 무게 × 횟수 입력, 세트 완료 체크, 종목 순서 변경/삭제, 메모
  - 이전 세션 기록이 각 세트 옆에 표시되고, 누르면 값이 채워짐
  - 새 세트는 직전 세트 값으로 자동 채움
  - 지난 날짜로 기록 추가 / 날짜 이동 가능
- **휴식 타이머** — 세트 완료 체크 시 자동 시작, ±15초, 종료 시 진동
- **캘린더** — 운동한 날 표시, 날짜별 기록 보기, 월간 요약
- **통계** — 주간 볼륨 그래프(8주), 연속 운동 주, 종목별 최고 무게·추정 1RM
- **종목 상세** — 추정 1RM / 최고 무게 / 볼륨 추이 그래프, 전체 기록
- **백업** — JSON 내보내기/가져오기(합치기 또는 교체), 엑셀용 CSV 내보내기
- 기본 종목 29개 + 직접 종목 추가, kg/lb 표시 단위, 기본 휴식 시간 설정

통계에는 **완료 체크한 세트**만 반영됩니다. 운동 완료 시 체크 안 한 세트가 있으면 모두 완료 처리할지, 삭제할지 묻습니다.

## 실행

```bash
npm install
npx expo start
```

휴대폰에 **Expo Go** 앱을 설치하고 터미널의 QR 코드를 스캔하면 바로 실행됩니다. 웹 브라우저에서 보려면 `w`를 누르세요.

## 개발

```bash
npm run typecheck   # 타입 검사
npm test            # 로직 단위 테스트 (통계, 백업, 리듀서)
```

### 구조

```
src/
  app/               Expo Router 화면
    (tabs)/          홈 · 캘린더 · 통계 · 설정
    workout/[id].tsx 운동 기록 화면
    routine/         루틴 상세 · 편집
    exercise/[id].tsx 종목별 기록/그래프
  lib/               순수 로직 (타입, 날짜, 통계, 백업/CSV, 파일 입출력)
  store/             상태(Context + reducer, AsyncStorage 저장), 휴식 타이머
  ui/                공용 컴포넌트, 차트·근육 그림(react-native-svg), 바텀시트, 테마
```

## 알려진 제한

- 데이터는 기기에만 저장됩니다. 기기 변경 전 JSON 백업을 내보내세요.
- 휴식 타이머는 앱이 화면에 떠 있을 때만 알림(진동)이 울립니다. 백그라운드 알림은 아직 없습니다.
- kg/lb 전환은 표시 단위만 바꾸며 값을 변환하지 않습니다.
